# Guia de Coolify

Documentació en català dels desplegaments a la instància de l’institut.

Amb Zensical instal·lat, executa `zensical serve` des d’aquest directori i obri l’adreça indicada al terminal. Executa `zensical build` per generar la web a `site/`.

Els continguts són a `docs/` i la navegació a `zensical.toml`.

Queda pendent incorporar l’adreça del panell, el procediment d’accés, el contacte de suport i els criteris d’assignació de dominis i recursos. Configura `site_url` quan es conega l’adreça pública de la guia.

## Exemple documentat

El tutorial segueix el desplegament de JustHub Garage des de GitHub amb Dockerfile, Zensical i Nginx. Les captures originals són a `docs/img/` i les notes de treball es conserven a `docs/log.md`. La guia publicada comença a `docs/index.md`; les notes no formen part del recorregut de navegació.

Abans de publicar captures noves, comprova que no mostren credencials ni dades personals.
